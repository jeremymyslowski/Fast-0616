# Fancy Hello World

## In Python

```python
def fancy_hello_world():
    print("\033[1;35mHello, World! 🌍✨\033[0m")
    print("This is a fancy Hello World in the borat branch!")

if __name__ == "__main__":
    fancy_hello_world()
```

## In JavaScript

```javascript
console.log('%cHello, World! 🌟', 'color: purple; font-weight: bold; font-size: 16px;');
```
